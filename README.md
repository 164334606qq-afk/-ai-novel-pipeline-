# AI-Assisted Novel Creation Pipeline

人机协同迭代创作系统，用于长篇网络小说的系统化生产。

## 项目状态

- 目标：完成一部长篇网络小说（预计15万字）
- 当前进度：13章完成，约3.5万字
- 工作流已跑通，处于稳定迭代阶段

## 核心工作流

阶段1：生成 → 输入梗概，AI写初稿
阶段2：精修 → 人工手动修改正文
阶段3：质检 → 回输修订稿，AI进行5维度技术分析
阶段4：协商 → 对AI质疑进行反驳或解释，达成共识
阶段5：收敛 → 修改后再次质检，直到双方认可

| 累计AI对话轮次 | 约200轮 |

## 为什么需要MiMo V2.5

1. 100万上下文：质检阶段需将整章修订稿（5K-10K字）+ 分析指令 + 前文摘要 + 协商历史一并输入，现有128K模型频繁截断
2. 跨章一致性：长篇小说需携带多章历史进行全局校验，当前模型无法支持
3. 深度协商：协商轮次多了之后，上下文截断导致AI"忘记"前面的讨论
4. 预计日均Token消耗：500K-2M
